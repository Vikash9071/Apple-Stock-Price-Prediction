# Apple Stock Price Prediction

This project predicts the future stock price of **Apple Inc. (AAPL)** using historical stock market data and machine learning models. The goal is to understand stock price trends and build predictive models for closing prices.

## Key Features
- Load and analyze historical stock price data
- Data preprocessing and visualization
- Train predictive models to forecast stock closing prices
- Compare classical ML models vs. deep learning models (LSTM)

## Models Used
Depending on your implementation, models may include:
- Linear Regression
- Random Forest Regressor
- ARIMA / SARIMA (Time-Series Model)
- LSTM Neural Network (Deep Learning model for sequential data)

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- RMSE
- R² Score

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib / Seaborn / Plotly
- Scikit-learn
- TensorFlow / Keras (if using LSTM)
